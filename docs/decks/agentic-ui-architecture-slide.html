@infra-tools/agentic-ui — Architecture at a Glance
A reusable Angular 21 library for building UIs an LLM can drive. One chat shell, one set of registries, one orchestration loop — running unchanged against AG-UI, Hashbrown, or A2UI, with first-class microfrontend federation.
